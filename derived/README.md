# Derived data

Generated by `python analysis/extract_results.py`; no experiment file is modified.

| File | Rows / contents | Evidence coverage |
|---|---|---|
| `e001_per_document.csv` | 64 document roster rows | No NLL observations; original LOCKED folder is absent |
| `e002_per_document.csv` | 64 independent documents | Eight factorial NLLs; native/corrected NLL recovered exactly from six ablation identities; TDD base |
| `e002_factorial_validation.csv` | 32 independent documents | Native and factorial NLL observations |
| `e002_ablation_per_document.csv` | 384 repeated-measure rows | Six ablations on 64 existing LOCKED documents |
| `headline_results.json` | Sealed headline values and explicit methods | Aggregate-only fields are distinguished from recomputed/recovered fields |
| `secondary_results.json` | Sealed factorial and state-convergence data | Supports secondary paper-figure values |

**No E001 outcomes or E002 baseline/control observations are synthesized.**
The E001 CSV is a cohort roster, not a complete result dataset. E002 does not
contain per-document continued-4B, empty-target, wrong-donor, NCR, or TQR.

E002 recovery uses `native = ablated_nll - delta_nll_to_native` and
`corrected = ablated_nll - impact_vs_joint_corrected`. Every one of six
ablations must agree for each document. The original writer and ordering
are documented in [REPRODUCIBILITY.md](../docs/REPRODUCIBILITY.md).

Exact source files and hashes are printed during extraction and included in
the headline JSON. Run `python analysis/verify_results.py --available-only`
for the bounded check; the default command requires complete primary
headline evidence and currently fails explicitly.

See [DATA_DICTIONARY.md](../docs/DATA_DICTIONARY.md) for units and columns.
