# Derived data

Generated by `python analysis/extract_results.py`. No sealed experiment file is modified.

| File | Rows / contents | Evidence coverage |
|---|---|---|
| `e001_per_document.csv` | 64 PG19 documents | Seven LOCKED condition NLLs from `locked/raw_evidence.jsonl` |
| `e002_per_document.csv` | 64 FineWeb-Edu documents | Factorial NLLs plus native, corrected, continued-4B, empty, and wrong-donor NLL from `locked/raw_evidence.jsonl` |
| `e002_factorial_validation.csv` | 32 validation documents | Native and factorial NLL from the validation factorial raw evidence |
| `e002_ablation_per_document.csv` | 384 repeated-measure rows | Six ablations on the 64 LOCKED documents |
| `headline_results.json` | Sealed headline values and recomputed document-mean intervals | `full_headline_reproduction_available` is true when extraction succeeds |
| `secondary_results.json` | Factorial effects, selection summary, fidelity, and state-convergence data | Machine-local absolute paths are rewritten to package-relative references |

E002 recovery still cross-checks `native = ablated_nll - delta_nll_to_native` and
`corrected = ablated_nll - impact_vs_joint_corrected`. Every one of six
ablations must agree for each document. The original writer and ordering
are documented in [REPRODUCIBILITY.md](../docs/REPRODUCIBILITY.md).

Exact source files and hashes are printed during extraction and included in
the headline JSON. Run `python analysis/verify_results.py` for the headline
integrity check.

See [DATA_DICTIONARY.md](../docs/DATA_DICTIONARY.md) for units and columns.
